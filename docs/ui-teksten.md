## Vacatures in de Ayla-chat (iOS)

Vacatures staan niet in het menu. Je zoekt ze in de chat met Ayla; ze openen in een paneel over de chat, net als de kluis.

| Onderdeel | Tekst |
| --- | --- |
| Kaart in de chat | 1 vacature gevonden / {n} vacatures gevonden |
| Titel paneel | Vacatures |
| Uitleg paneel | Vraag Ayla hieronder iets over deze vacatures. |
| Tabs | Gevonden {n} / Bewaard {n} |
| Knoppen | Bewaren / Bewaard / Vraag Ayla |
| Vacature (titel) | Vacature |
| Stukje tekst | Uit de vacaturetekst |
| Uitleg bij het stukje (Adzuna, Jooble) | Een stukje van de tekst, zoals {Adzuna/Jooble} het geeft. De hele vacature lees je bij de werkgever. |
| Uitleg bij het stukje (internet) | Een stukje van de pagina waar Ayla deze vacature vond. Controleer de hele vacature op die site. |
| Wat past | Past bij jou |
| Wat ontbreekt | Wat je nog mist |
| Uitleg vergelijking | Ayla vergeleek je kluis met een stukje van de vacaturetekst. Het is een inschatting, geen oordeel. |
| Nog niet vergeleken | Ayla heeft deze vacature nog niet met je kluis vergeleken. Vraag het haar hieronder. |
| Link naar de werkgever | Lees de hele vacature |
| Bron | Vacatures via Adzuna / Vacatures via Jooble / Gevonden op internet |
| Bewaard leeg | Nog niets bewaard - Tik op Bewaren bij een vacature om hem hier terug te vinden, ook op je andere apparaten. |
| Gevonden leeg | Nog geen vacatures - Vraag Ayla hieronder bijvoorbeeld: zoek vacatures die bij me passen. |
| Vraag bij een ontbrekende vaardigheid | Hoe kan ik {vaardigheid} halen voor {functie} bij {bedrijf}? |
| Bewaren mislukt | Bewaren lukte niet. Probeer het opnieuw. |
| Laden mislukt | Je bewaarde vacatures konden niet worden geladen. |
| Ayla zoekt (één regel, waar "Ayla denkt na…" staat) | Ayla zoekt vacatures: {zoekwoorden} (en {verwante functie}) in {plaats}… |
| Ayla vergelijkt (met gekozen gegevens) | Ayla vergelijkt {n} vacatures met wat je koos… |
| Vraag om de kluis (iPhone) | Ja / Kies zelf / Nee |
| Ayla als je zelf wilt kiezen | Kies maar. Ik gebruik alleen wat je kiest. |
| Bol terwijl je met de hand kiest | Ayla wacht tot je klaar bent |
| Na "Kies zelf" (jouw bericht) | Gebruik het item dat ik koos. / Gebruik de {n} gegevens die ik koos. |
| Boven de gevonden vacatures | Gezocht op: {zoekwoorden} (en {verwante functie}) in {plaats} |
| Welke gegevens Ayla gebruikte (rij) | Uit je kluis: {categorieën} / Met {n} gekozen gegevens / Met 1 gekozen item / Zonder je kluis |
| Rechts in die rij | Wijzig / Kies |
| Op de kaart | {n} van {m} vaardigheden passen |
| Datum in de vacature | Geplaatst op {dag} {maand} |
| Ayla vergelijkt (met kluis) | Ayla vergelijkt {n} vacatures met je kluis… |
| Ayla bekijkt (zonder kluis) | Ayla bekijkt {n} vacatures… |

## Iets doen met een vacature (iOS, chat en praten met Ayla)

Onder een vacature staan vier acties. Tik je erop, dan komt de vraag als jouw bericht in de chat en antwoordt Ayla. Vergelijken doe je door 2 of 3 vacatures te kiezen.

| Onderdeel | Tekst |
| --- | --- |
| Knoppen | Wat mis ik? / Solliciteren / Oefen gesprek / Vergelijk |
| Vergelijk gekozen | Gekozen |
| Knop met 2 of 3 gekozen | Vergelijk {n} vacatures |
| Met 1 gekozen | Kies nog een vacature om te vergelijken |
| Al 3 gekozen | Je kunt er 3 tegelijk vergelijken |
| Jouw bericht: vergelijken | Vergelijk {functie} bij {bedrijf} met {functie} bij {bedrijf}. Welke past het best bij mij? |
| Jouw bericht: wat mis ik | Wat mis ik nog voor {functie} bij {bedrijf}, en hoe kom ik daar? |
| Jouw bericht: solliciteren | Help me solliciteren op {functie} bij {bedrijf}. |
| Jouw bericht: oefenen | Oefen een sollicitatiegesprek met mij voor {functie} bij {bedrijf}. |
| Tijdens het oefenen | Oefengesprek · {bedrijf} / Stoppen |
| Jouw bericht bij Stoppen | Ik wil stoppen met oefenen. |

## Wat Ayla zelf doet in de app (iOS)

Ayla zegt in haar eigen woorden wat ze doet. Deze vaste teksten komen van de app zelf.

| Onderdeel | Tekst |
| --- | --- |
| Vraag vooraf: gesprek verwijderen | Zal ik dit gesprek verwijderen? |
| Vraag vooraf: bewijs verwijderen | Zal ik "{titel}" uit je kluis verwijderen? Dat kan niet ongedaan worden gemaakt. |
| Vraag vooraf: meer bewijs verwijderen | Zal ik "{titel}" en "{titel}" uit je kluis verwijderen? Dat kan niet ongedaan worden gemaakt. |
| Vraag vooraf: uitloggen | Zal ik je uitloggen? |
| Vraag vooraf: alles vergeten | Zal ik alles vergeten wat ik over je onthoud? Dat kan niet ongedaan worden gemaakt. |
| Na Ja | Ik heb het gesprek verwijderd. / Ik heb {titel} uit je kluis verwijderd. / Ik heb alles vergeten wat ik over je onthield. / Ik log je uit. |
| Map niet gevonden | Ik kon de map {naam} niet vinden. |
| Staat al zo | Dat staat al zo. |
| Iets vergeten wat Ayla niet onthoudt | Dat onthoud ik niet, dus er is niets om te vergeten. |
| Iets vergeten terwijl het geheugen uit staat | Ik onthoud niets tussen gesprekken, dus er is niets om te vergeten. |
| Bewijs niet gevonden | Ik kon {naam} niet vinden in je kluis. |
| Gesprek niet gevonden | Ik kon geen gesprek vinden over {naam}. |
| Gesprek nog niet in de lijst | Dit gesprek staat nog niet in je lijst, dus dat lukt nu nog niet. Probeer het zo opnieuw. |
| Onbekende keuze | Dat kon ik niet instellen: die keuze ken ik niet. |
| Lukt niet | Dat lukt nu niet. |
| Map bestond al | De map {naam} bestond al. Ik open hem. |
| Vraag vooraf: Ayla toegang geven | Mag ik "{titel}" voortaan bekijken en gebruiken? |
| Vraag vooraf: Ayla toegang geven tot meer bewijs | Mag ik "{titel}" en "{titel}" voortaan bekijken en gebruiken? |
| Vacatures gevonden, maar Ayla kon er niets over zeggen | Dit heb ik gevonden. Er meer over vertellen lukte me nu niet; vraag gerust door over een van deze vacatures. |
| Na Ja op toegang | Ik mag {titel} nu bekijken en gebruiken. |
| Statuspil als ze klaar is | {n} dingen gedaan / {n} dingen gedaan, {m} niet gelukt / Dat lukte niet |
| Statuspil, voortgang | {stap} van {aantal} |
| Buiten de app (vergrendelscherm, Dynamic Island) | Ayla is bezig - Stap {n} van {m} / Zoekt vacatures / Vergelijkt vacatures / Gaat verder |
| Ayla gaat zelf verder | Ayla gaat verder… / Verder gaan lukte nu niet. Probeer het zo opnieuw. |
| Stappen (voorbeelden) | Donker aanzetten / Map {naam} openen / Chat {titel} noemen / Chat vastzetten / Map {naam} maken / {bewijs} in de map {naam} zetten |
| Kleine bol op een pagina | Ayla luistert… / Ayla denkt na… / Ayla praat / Je microfoon staat uit |
| Stappen bij vacatures zoeken | Vacatures zoeken / {n} vacatures gevonden / Vergelijken met je kluis / Vacatures bekijken / Lijst openen |
